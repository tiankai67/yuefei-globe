# 岳飞抗金征程 · 3D 地球可视化

基于 Three.js 的**单文件网页**，在 3D 地球上按史实路线重现岳飞一生的抗金征程。

岳飞骑马小人沿路线跑动，实时留下贴合球面大圆弧度的红色轨迹，实时计算已走公里数，并显示当前站点的历史事件说明。附带内嵌背景音乐与一键录屏导出。

## ✨ 特性

- 🌍 可拖拽旋转、滚轮局部放大的 3D 地球
- 🗺️ 中国省级行政区划贴图（DataV GeoJSON）
- 🐎 岳飞沿 68 个史实站点跑动，轨迹贴合球面大圆
- 📏 实时公里数、当前站点历史事件文字说明
- 🎵 内嵌背景音乐，可手动点亮播放
- 🎬 一键录屏：岳飞从头跑 + 播音乐 + 录屏，结束自动生成 MP4（带声音）
- 🎯 自动聚焦跟随岳飞

## 🚀 使用

直接用浏览器打开 `index.html` 即可（需联网加载 Three.js 与行政区划数据）。

- 点击 `♪ 音乐` 手动播放背景音乐
- 点击 `● 录屏`：岳飞从头开始跑、同时播放音乐并录屏，跑到终点后浏览器自动下载 MP4

## 🧰 技术栈

- Three.js (r160) + OrbitControls
- DataV 省级 GeoJSON 行政区划数据
- `canvas.captureStream` + `MediaRecorder` 录屏导出
- 单 HTML 文件，背景音乐以 base64 内嵌
